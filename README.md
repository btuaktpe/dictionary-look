# Dictionary Look

Dictionary-style typography for Obsidian, paired with native macOS HUD glass.

![Dictionary Look](preview.png?v=2)

## Install

Download the [latest release](https://github.com/btuaktpe/dictionary-look/releases/latest) and extract it into:

```text
.obsidian/plugins/dictionary-look/
```

Reload Obsidian, then enable **Dictionary Look** under **Settings → Community plugins**.

Requires Obsidian 1.6.0 or later.

## Markup

- `#` — headword
- `##` — homograph
- `> | … |` — pronunciation
- `==noun==` — label
- `####` — origin
- `*text*` — muted
- `_text_` — example

> Native HUD glass is available on macOS. Dictionary typography uses Obsidian’s dark appearance.
